# Массовое добавление вопросов

## Описание
Добавлена новая функциональность для массового добавления вопросов к лекциям в админ панели. Теперь администраторы могут создавать несколько вопросов одновременно, что значительно упрощает процесс создания тестов.

## Новые возможности

### 1. Кнопка "Массовое добавление"
- Расположена в заголовке страницы "Управление тестами"
- Позволяет открыть специальное модальное окно для создания нескольких вопросов

### 2. Модальное окно массового добавления
- **Выбор лекции**: Выберите лекцию, к которой будут добавлены вопросы
- **Динамическое добавление вопросов**: Кнопка "+ Добавить вопрос" для создания новых вопросов
- **Удаление вопросов**: Возможность удалить ненужные вопросы (кроме первого)
- **Валидация**: Проверка заполнения всех полей и наличия правильных ответов

### 3. Структура вопроса
Каждый вопрос содержит:
- Текст вопроса (обязательное поле)
- 4 варианта ответа (все обязательны)
- Отметка правильного ответа (хотя бы один должен быть правильным)

### 4. Валидация
Система проверяет:
- Выбор лекции
- Заполнение текста каждого вопроса
- Заполнение всех вариантов ответов
- Наличие хотя бы одного правильного ответа для каждого вопроса

### 5. Массовое создание
- Все вопросы создаются последовательно
- Показывается прогресс создания
- Автоматическое обновление списка вопросов после создания

## Использование

1. Перейдите в админ панель → Управление тестами
2. Нажмите кнопку "📝 Массовое добавление"
3. Выберите лекцию из выпадающего списка
4. Заполните первый вопрос и его варианты ответов
5. При необходимости добавьте дополнительные вопросы кнопкой "+ Добавить вопрос"
6. Отметьте правильные ответы чекбоксами
7. Нажмите "Создать X вопросов" для сохранения

## Технические детали

### Компоненты
- `BulkQuestionModal.tsx` - основное модальное окно
- `BulkQuestionModal.module.scss` - стили для модального окна
- Обновлен `TestManagement.tsx` для интеграции новой функциональности

### API
Использует существующий API для создания вопросов:
- `createQuestion()` - для создания каждого вопроса
- Последовательное создание всех вопросов

### Стили
- Адаптивный дизайн для мобильных устройств
- Современный UI с анимациями и переходами
- Цветовая схема соответствует общему дизайну приложения

## Преимущества

1. **Экономия времени**: Создание нескольких вопросов за один раз
2. **Удобство**: Не нужно закрывать и открывать форму для каждого вопроса
3. **Валидация**: Проверка данных перед отправкой
4. **Гибкость**: Возможность добавлять и удалять вопросы динамически
5. **Адаптивность**: Работает на всех устройствах

## Обратная совместимость
Новая функциональность не влияет на существующую систему добавления одиночных вопросов. Все старые функции продолжают работать как прежде.
